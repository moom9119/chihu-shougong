# 怎么启动

三种场景，按你的需要挑一个：

| 你想干什么 | 怎么做 | 花多久 |
|---|---|---|
| **只想看看这个作品** | 双击 `赤狐收工.html` | 5 秒 |
| 想先看作品介绍 | 双击 `作品介绍.html`，右上角「打开作品」 | 1 分钟 |
| 想改代码 / 看实现 | `cd 源码` → `node tools/serve.mjs` | 2 分钟（需 Node 18+） |
| 想要一个公网链接 | `node tools/build-deploy.mjs` → 拖到 Netlify Drop | 2 分钟 |

---

## 一、直接打开（推荐，Windows / macOS 都行）

1. 打开文件夹 `赤狐收工-评审交付版`
2. **双击 `赤狐收工.html`**
3. 用 Chrome / Edge / Safari / Firefox 的新版打开（2022 年以后发布的版本都行）

不需要装任何东西，不需要联网，不需要起服务。所有图片、音乐、代码都在这一个文件里。

> **第一次打开会看到什么**：首页写着「第一次使用：三步就绪」，右上角总开关是**关**的。
> 这是故意的 —— 免得你半夜点开直接被锁在黑屏上。想看效果就点首页的「试跑 60 秒」。

### 从 zip 开始的话

1. 右键 `赤狐收工-评审交付版.zip` → **全部解压**（Windows 自带解压就行）
2. 进解压出来的文件夹，再双击 `赤狐收工.html`

> ⚠️ 不要在压缩软件里直接双击：那会解到临时目录，你的设置和进度下次打开就没了。

---

## 二、手机上怎么看

- **安卓**：把 `赤狐收工.html` 传到手机 → 用 Chrome / 文件管理器「用浏览器打开」
- **iPhone**：传到「文件」App → 长按 → 共享 → 用 Safari 打开（iOS 的快速预览不支持，必须用 Safari）
- 微信/QQ 直接发 17 MB 文件可能被拦，建议发 zip 或走网盘

手机上的效果和电脑一致（本来就是按 430px 手机屏设计的）。

---

## 三、开发模式（要看源码、要改功能）

需要一个本地服务，因为源码是 ES Modules，浏览器不允许从 `file://` 加载模块。

**Windows 一键**：双击 `start.cmd`（会自动找 Node、起服务、开浏览器）。

**手动**：

```powershell
cd 源码
node tools/serve.mjs            # 打开 http://127.0.0.1:7317
node tools/serve.mjs --port 8080   # 换端口
node tools/serve.mjs --no-open     # 不自动开浏览器
```

需要 Node.js ≥ 18（只用于起服务和跑脚本，作品本身不需要 Node）。

**改完代码要重新打包**，否则 `赤狐收工.html` 还是旧的：

```powershell
node tools/build-single.mjs --prod     # 重新生成交付版单文件
```

## 四、想要一个公网链接（提交表要求填 URL 时）

作品本身是本地单文件、没有部署过。要网址的话：

```powershell
node tools/build-deploy.mjs      # 生成 交付/部署/ 文件夹（静音版 2.7 MB）
```

1. 打开 <https://app.netlify.com/drop>
2. 把 `交付/部署` 这个文件夹整个拖进去
3. 立刻得到一个 `https://xxx.netlify.app` 的网址

也支持 GitHub Pages / Cloudflare Pages / Vercel，步骤写在 `交付/部署/部署说明.md` 里。

> 部署包是**静音版**：公开托管属于对外分发，而背景音乐是第三方版权，已经刻意剥离。
> 功能一模一样，只是没有音乐。

## 五、启动后 60 秒自检

打开后按这个顺序点一遍，能全部对上就说明跑起来了：

1. 首页大标题是「现在可以自由使用」或「限制功能总开关关着」
2. 点首页 **「试跑 60 秒」** → 全屏锁定、界面变灰、小狐狸出现、倒计时 `01:00`
3. 点 **「我用手机了」** → 弹出数字矩阵，16 个格子
4. 按 1→2→3… 顺序点完 → 矩阵关闭
5. 切到别的窗口停 3 秒再回来 → 小狐狸变成哭脸，提示「你刚才离开了」
6. 按住页面底部那条虚线 **3 秒** → 结算页 → 点「收下」→ 回到首页
7. 去「记录」页 → 限制时段里加一段、关掉一个开关、删一段（删要连点两下确认）
8. 顶栏右上角有 `🔉 30%` → 点一下变 `🔊 50%`（**静音版没有这个按钮**，属正常）

## 六、常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 双击后白屏、一直转圈 | 浏览器太老（需要支持 ES2020 的版本）；或文件没拷完整，正常是 **17.35 MB** |
| 双击没反应 | Windows 没关联默认浏览器：右键 → 打开方式 → Chrome / Edge |
| 没有声音 | ① 浏览器要求先点一下页面才允许出声；② 这次构建是静音版（顶栏没有喇叭按钮，设置页会写明） |
| 被锁住了，怎么退出 | 按住底部虚线 **3 秒** → 结算页 → 收下。或在「设置」里关掉总开关 |
| 设置/进度会不会丢 | 存在浏览器 localStorage（`foxlock.*` 六个键）。清缓存、换浏览器、换电脑就没了 |
| 怎么清空数据 | 设置 → 恢复默认（两步确认）；记录页 → 清空记录（收藏册不受影响） |
| 能不能离线用 | 能。全程零网络请求，`Network` 面板只有页面自身 |
| 手机上打不开 | iOS 必须用 Safari 打开本地 html；安卓用 Chrome。用微信内置浏览器可能被限制 |
| 想看它怎么实现的 | 双击 `作品介绍.html`，或直接读 `源码/`（`src/core/engine.js` 是状态机） |
